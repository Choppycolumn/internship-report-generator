# 第一阶段实施方案与验收标准

## 实施范围

1. 建立完整目录骨架和项目初始化命令。
2. 导入并分类学校要求资料，保留来源、哈希和导入时间。
3. 导入 JPG、PNG、TIFF、PDF 模板，保留原件，不覆盖同名文件。
4. 模板物理尺寸默认为空；只有用户执行 `template set-size` 后才能启用毫米坐标。
5. 提供页面四角检测、透视校正和旋转校正接口，原始扫描永不覆盖。
6. 使用左上角为原点的毫米坐标模型，提供毫米与像素、PDF 点之间的确定性转换。
7. 提供人工正文区、禁打区、图片区、表格区、字段区和横线的可视化标定界面。
8. 提供绝对坐标文本渲染、带背景预览、无背景套打和调试 PDF。
9. 提供打印机偏移、横纵缩放和旋转补偿模型，以及校准页。
10. 在生成正式 PDF 前检查页面越界、禁打区碰撞、过小字号和配置缺失。

## 状态门禁

```text
imported -> awaiting_physical_size -> size_confirmed -> corrected -> calibrated
```

PDF 自带介质框、图片 DPI 和像素比例都不能让模板自动进入 `size_confirmed`。

## 第一阶段验收标准

- 可无覆盖地导入学校要求图片和模板候选。
- 未设置宽高的模板执行预览、校正、校准页或套打时明确失败。
- 设置任意非 A4 测试尺寸后，生成 PDF 的介质框与输入毫米尺寸一致。
- 坐标往返误差不超过 0.01 mm。
- 正文区和禁打区均以毫米保存，并能在调试图层显示。
- 预览 PDF 有背景，正式套打 PDF 无背景，调试 PDF 有坐标和区域。
- 打印补偿按“偏移 -> 缩放 -> 旋转”的统一模型应用并有单元测试。
- 严重越界或禁打区碰撞阻止正式套打 PDF。
- 合成样例完成 PDF 生成、PNG 渲染和人工目检；不得把合成尺寸应用于真实模板。
