# 第二阶段测试与视觉检查报告

日期：2026-07-10

## 实现范围

- 基于 Pillow 和 NumPy 的横线检测，不依赖 OpenCV。
- 自动检测结果保存在 `detected_writing_lines`，默认不覆盖人工横线。
- 使用 ReportLab 实际字体度量完成中文、英文、数字和标点换行。
- 禁止右标点出现在行首，禁止左括号、书名号等孤立在行末。
- 段落首行缩进，续行返回正文左边界。
- 每条文字基线使用模板中对应横线的真实 y 坐标，并应用可配置中文垂直偏移。
- 标题与下一段绑定，避免标题孤立在页底。
- 跨页段落预演当前页和下一页，避免下一页只剩一行。
- 第一页和续页可使用不同模板；续页模板横线允许轻微不等距。
- 页码只写入人工标定的页码区域。
- 多页预览、正式套打和调试 PDF 输出。
