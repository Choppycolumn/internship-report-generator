# 第四阶段验收报告：每日内容与人工审核

验收日期：2026-07-11

## 已完成

- 保存每日审核时保留 `metadata.json` 中的地点、人员、已确认操作和禁写项。
- 将材料分为已确认事实、合理推断、待确认内容和禁止写入内容。
- 生成不使用推断事实的安全草稿框架。
- 支持 Codex 在当前工作区读取材料包并写回简化结构化草稿。
- 统计每日正文、各段字数和距离目标字数。
- 对近期已批准日期进行段落相似度检查。
- 待确认、禁写命中、未审核图片、占位文本和高重复内容会阻止批准。
- 批准后同步锁定 drafts、approved 和 structured 三份状态，旧草稿不能继续编辑。
- 审核网页可编辑事实四栏、草稿段落、图片说明和确认状态。

## 无外部模型 API 模式

内容生成不要求 OpenAI API Key。Codex 通过本地工作区直接读取：

- `days/YYYY-MM-DD/notes.txt`
- `days/YYYY-MM-DD/metadata.json`
- 当日处理照片及人工图题
- `reports/approved/` 中最近七天的摘要

生成结果使用 `CodexDailyDraftInput` 简化结构写回，再由确定性本地引擎计算指标和锁定状态。审核网页的 HTTP 接口只监听 `127.0.0.1`。
