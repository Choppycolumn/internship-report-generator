## 简介

学校允许打印实习报告，但真正麻烦的不是按下“打印”，而是让文字、照片和图题准确落在报告册原有的横线与栏目里，还不能盖住页眉、表格、签字区和装订边。

所以我做了这个“生产（专业）实习报告智能生成与精确套打系统”。它会按实测纸张尺寸建立毫米坐标，读取每一条真实横线的位置，再把中文、照片和图题确定性地排进去。每天可以上传实习照片，在每张图片下方检查对应文字、图题和确认状态；排版完成后会同时生成带背景预览 PDF、无背景套打 PDF 和坐标调试 PDF。

这个项目是用约 5.6 SOL、极高强度、经历两次重置才完成到现在的产物。目前四个阶段主体已经跑通：模板标定、横线排版与分页、图片处理与图文混排、每日事实审核与草稿锁定，36 项测试全部通过。

我刻意保留了几个边界：不把学校《使用注意事项》当模板，不在缺少尺寸时默认 A4，不把照片推测成确定事实，也不会假装完整 8000 字总报告功能已经完成。真实套打仍要等纸张实测尺寸和普通纸试打校准。

代码会放在公开 GitHub 仓库。适合也在写生产实习、课程设计报告，或者对“固定格式纸张精准打印”感兴趣的同学参考。
