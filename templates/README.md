# HUST 公开扫描模板与标定参数

此目录包含一套经提供者明确同意公开的真实空白报告纸。其他导入的模板仍由 `.gitignore` 默认排除；公开例外仅匹配下面四个具体文件，不开放整个模板目录。

## 文件

模板编号：`lined_content_page_candidate`。

| 文件 | 用途 |
| --- | --- |
| [原扫描 PDF](raw/手写_2026-07-10_110724.pdf) | 原始单页扫描件，保持原文件不变 |
| [源图预览](preview/lined_content_page_candidate_source.png) | 从扫描件提取的原始页面图像 |
| [校正图](corrected/lined_content_page_candidate.png) | 已旋转校正的背景图，用于预览和标定 |
| [模板配置](config/lined_content_page_candidate.json) | 页面尺寸、区域和基线的毫米坐标及历史标定记录 |

页面仅有“华中科技大学生产（专业）实习报告”固定页眉及其下方横线，正文为空白。它不是《使用注意事项》要求页。文件不含学生姓名、学号、手写签字、每日照片或报告正文；扫描 PDF 未发现作者信息、批注、链接或嵌入附件，PNG 未包含 EXIF 信息。

## 尺寸与标定状态

- 提供者给出的页眉横线真实长度为 **152 mm**。
- 当前配置保留的页面尺寸为 **180.876 × 258.484 mm**。历史记录包含由横线推算尺寸及后续用户确认的过程；这里没有重新测量，也没有将扫描件改为 A4。
- 原始扫描 PDF 的介质框约为 **168.981 × 241.653 mm**，只是扫描软件生成的文件尺寸，不能直接作为实物纸张尺寸。应用预览以配置中的物理尺寸为准。
- 正文候选区为 `x=16.909, y=38, width=151.999, height=200 mm`。
- 正文中的 29 条基线是配置的**虚拟排版线**，从 `y=42 mm` 开始、间隔 `7 mm`，不是从原纸正文检测出的预印横线。
- 配置状态仍为 `corrected`，正文候选区、虚拟行距和装订侧尚有待复核项。为保留现有项目数据，本次公开不修改坐标、不清除历史标记，也不将其升级为 `calibrated`。

这套模板用于复现当前项目和人工调整。即使模板校验通过，也不能据此保证另一册报告纸或另一台打印机已经精确对齐。

## 使用

安装项目依赖后，在仓库根目录执行：

```powershell
.venv\Scripts\python cli.py template validate lined_content_page_candidate
.venv\Scripts\python cli.py template preview lined_content_page_candidate
.venv\Scripts\streamlit run app.py
```

配置中所有素材路径均相对于项目根目录，没有本机绝对路径。现有 v1 配置可由程序兼容加载，不要求先修改原文件。

纸张和区域标定参数完整保存在上述模板 JSON 中；字号、首行缩进及全局文字基线偏移保存在已公开的 [排版样式配置](../config/style.json) 中。当前项目没有已保存的个人打印机补偿配置，因此本次不附带或编造打印机参数。

预览 PDF 包含校正扫描背景；正式套打 PDF 只输出新增内容。不要将原始扫描 PDF 直接作为套打文件。实际打印前仍应复核手中纸张的尺寸和可打印区域，使用普通纸以实际大小 100% 测试，并校准打印机偏移。
